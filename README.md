🕹️ How to Play
Clone the repository:
git clone https://github.com/your-username/RockPaperScissors.git
cd RockPaperScissors

Run the game:
python rps.py

Enter your choice:
1 for Rock
2 for Paper
3 for Scissors
The bot will make its move, and the result will be displayed instantly.
